# API-007 : Pricing
## 1. Simulate
`POST /api/pricing/simulate`
Request:
```json
{ "pa": "3.41", "rate": "655.957", "profileId": "uuid" }
```
Response:
```json
{ "paCfa": "2237", "prCfa": "3359", "pvHtCalcule": "3695", "pvTtc": "4360" }
```
## 2. Autres
- `GET /api/pricing/profiles`
- `POST /api/pricing/profiles`
- `PUT /api/pricing/products/{id}/apply-price`
