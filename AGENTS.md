## Documentation 

Le dossier `wiki/` contient la base de connaissance complète du projet.

Processus obligatoire :

1. Identifier les notes liées à la tâche.
2. Lire les liens entrants et sortants.
3. Comprendre les règles métier concernées.
4. Vérifier l'impact sur l'architecture.
5. Implémenter.
6. Mettre à jour la documentation.

La documentation est considérée comme la source de vérité du projet.
