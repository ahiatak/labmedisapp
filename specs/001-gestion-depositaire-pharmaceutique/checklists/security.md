# Security, RBAC & Audit Checklist: Système de Gestion LABMEDIS (Dépositaire Pharmaceutique)

**Purpose**: Validate the requirements-quality of authentication, JWT/refresh token lifecycle, the 10-role RBAC permission matrix, account lockout policies, sensitive action audit logging, soft-delete data integrity, financial masking, and rate limiting (US2, FR-012 to FR-019, FR-084, FR-089, FR-092; Constitution Principles III, IV, VII, and Security section). This is a standard-depth PR-review checklist for a peer reviewing spec.md before/during code review, with particular emphasis on access rights, permission boundaries, and audit trail inviolability.
**Created**: 2026-08-31
**Feature**: [spec.md](../spec.md)

**Note**: This custom checklist is generated by the `/speckit-checklist` command based on feature context and requirements.
**Review Ownership**: This checklist is a reviewer-owned requirements-quality review artifact. Mark an item `[x]` only when the reviewer determines the requirements-quality criterion is satisfied.
**Marker Semantics**: `[x]` means the criterion has been reviewed and satisfied for requirements quality. It does not mean implementation work is complete.
